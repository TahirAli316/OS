# How to Download Your GitHub Recovery Codes

## What are Recovery Codes?

Recovery codes are one-time use codes that allow you to access your GitHub account if you lose access to your two-factor authentication (2FA) device. They are essential for maintaining access to your account in case of device loss, failure, or replacement.

## Prerequisites

- You must have two-factor authentication (2FA) enabled on your GitHub account
- You must be logged into your GitHub account

## Step-by-Step Instructions to Download Recovery Codes

### Method 1: Through GitHub Settings (Web Browser)

1. **Log in to GitHub**
   - Go to [https://github.com](https://github.com)
   - Sign in with your username and password
   - Complete the 2FA verification if prompted

2. **Navigate to Security Settings**
   - Click on your profile picture in the top-right corner
   - Select **Settings** from the dropdown menu
   - In the left sidebar, click on **Password and authentication**

3. **Access Two-Factor Authentication Settings**
   - Scroll down to the "Two-factor authentication" section
   - You should see that 2FA is enabled

4. **View or Generate Recovery Codes**
   - Look for the option that says **"View recovery codes"** or **"Download recovery codes"**
   - Click on it
   - You may be prompted to confirm your password or authenticate again

5. **Download or Save Your Recovery Codes**
   - GitHub will display a list of recovery codes (typically 16 codes)
   - Click the **Download** button to save them as a text file
   - Alternatively, you can manually copy the codes to a secure location

### Method 2: Regenerate Recovery Codes

If you need new recovery codes (e.g., if you've used many of them or lost them):

1. Follow steps 1-3 from Method 1
2. Click on **"Generate new recovery codes"**
3. **Important**: This will invalidate all previous recovery codes
4. Download or save the new codes immediately

## Best Practices for Storing Recovery Codes

### ✅ DO:
- **Print them out** and store the printout in a secure physical location (safe, locked drawer)
- **Save them in a password manager** with strong encryption
- **Store them offline** in an encrypted file on a USB drive kept in a secure location
- **Keep multiple copies** in different secure locations
- **Treat them like a password** - anyone with these codes can access your account

### ❌ DON'T:
- Don't store them in plain text on your computer or phone
- Don't share them with anyone
- Don't store them in unencrypted cloud storage
- Don't take a screenshot and leave it in your photo library
- Don't email them to yourself

## Using a Recovery Code

If you lose access to your 2FA device:

1. Go to GitHub login page and enter your username and password
2. When prompted for 2FA, look for the option **"Enter a two-factor recovery code"**
3. Enter one of your recovery codes
4. **Important**: Each code can only be used once. After using a code, it's recommended to:
   - Generate new recovery codes
   - Set up a new 2FA method

## Troubleshooting

### I don't see the option to view recovery codes
- Make sure you have 2FA enabled on your account
- If 2FA is not enabled, you need to set it up first before you can get recovery codes

### I've lost my recovery codes and can't access my 2FA device
- If you still have access to your account, immediately generate new recovery codes
- If you're completely locked out, you'll need to [contact GitHub Support](https://support.github.com/contact)

### My recovery codes aren't working
- Ensure you're entering the code correctly (no spaces or typos)
- Remember that each code can only be used once
- If you've regenerated codes, old codes will no longer work
